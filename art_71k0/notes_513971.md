# Notes toward an MO 513971 answer/comment (alternating lexicographic sorting)

Poster asks: asymptotics of μ_n = E[T] for Bernoulli(1/2) matrices.

## What we can contribute (all verified, see verification.md)

1. **Row-multiset reduction.** A⁽¹⁾ = R(A) depends only on the multiset of
   rows of A, hence so does T. Exact computation therefore needs
   C(2ⁿ+n−1, n) evaluations, not 2^{n²}: new exact values
   - μ₅ = 36 573 599 / 2²⁴ = 2.179956377…
   - μ₆ = 168 401 367 693 / 2³⁶ = 2.450562427…
   - μ₇ = (this run; 9.36×10¹⁰ multisets)
   with full exact distributions of T (weighted); worst case 2n−3 attained at
   every n ≤ 7 (exhaustive; witnesses available).

2. **Empirical law.** MC (~390k matrices, n up to 16384): local slope of μ_n
   against ln ln n falls from ≈2 (n ≈ 10–100, the poster's range) toward
   ≈ 1.4 ≈ 1/ln 2 for n ≥ 10³. Proposed:
   **μ_n = log₂ log₂ n + C + o(1)** (equivalently (ln ln n)/ln 2 + C′).

3. **Mechanism (measured).** Define the settled depth d_t = number of leading
   columns (resp. rows) of A⁽ᵗ⁾ agreeing with the final fixed point. Observed:
   d_t roughly doubles per R+C round until it reaches ≈ 2 log₂ n (the depth
   at which all row-prefixes are distinct whp), and the final sort snaps the
   remainder at once (e.g. n=4096: 8 → 13 → 21 → 1918 → 4096). Rounds to
   double from O(log n) to 2 log₂ n with occasional stalls gives the
   log₂ log₂ n scale. A proof would need the stall-probability structure.

4. **Order-invariance in law.** Starting with C instead of R: T has the same
   distribution (transpose bijection), but on the SAME matrix the two
   processes are nearly independent: T_R ≠ T_C on ~57–60% of samples,
   corr ≈ −0.02 (n = 64, 256); the two fixed points differ on ~1.6% of
   entries at n=4096, c=32.

Decision: this is comment/answer-grade for the exact-values part; the
asymptotic claim should be posted as data + conjecture, not as a theorem.
