# MO 514645 — local maximality of the regular odd polygon (Erdős–Herzog–Piranian)

**Question** (0 answers): is it known that the regular odd n-gon of diameter 2
is a strict constrained local maximizer of Δ(r) = ∏_{i<j} |r_i−r_j|²
modulo E(2), with a quadratic stability estimate
log Δ(r°) − log Δ(r) ≥ c_n · dist(r, O_n)²?

We did not find such a reference either; this run's contribution is a complete
*computation* of the second-order picture (answer-grade numerics + one exact
lemma), for every odd n up to 201.

## Setup
Configuration space ℝ^{2n}, constraints g_ij = |r_i−r_j|² − 4 ≤ 0.
At the regular n-gon with circumradius R = 1/cos(π/2n) the active set is the
n "diameter" pairs (i, i±(n∓1)/2) — the star-polygon cage. Objective
F = Σ_{i<j} log|r_i−r_j| (so log Δ = 2F).

## Lemma (exact multiplier)
KKT: ∇F = Σ_active μ_a ∇g_a with **μ_a = (n−1)/16 for every a and every odd n**.
Proof: at vertex v₀ = R of p(z) = zⁿ − Rⁿ, Σ_{j≠0} 1/(v₀−v_j) = p″(v₀)/2p′(v₀)
= (n−1)/(2R), so ∇F at the vertex is radial of magnitude (n−1)/(2R).
The two active chords at v₀ contribute 2μ(2v₀ − v_a − v_b), and
v_a + v_b = −2R cos(π/n)·(v₀/R), so the constraint side is radial of magnitude
2μ·2R(1+cos π/n) = 8μR cos²(π/2n) = 8μ/R (using R = 1/cos(π/2n)).
Equating (n−1)/(2R) = 8μ/R gives μ = (n−1)/16. ∎
(numerically exact, spread < 3·10⁻¹⁴, for all odd n ≤ 201; μ > 0 = strict
complementarity.)

## Second-order verification (n = 5, 7, …, 61, 75, 101, 151, 201)
- Critical cone C = null(∇g_active) has dim 2n − n = n; the isometry algebra
  (2 translations + rotation) lies inside C; on C ⊖ iso (dim n−3) the
  Lagrangian Hessian H = ∇²F − Σ μ_a ∇²g_a is **negative definite for every n
  tested** — λ_max ranges from −1.8090169944 at n=5 (matching the surd
  −(5+√5)/4 to 10 digits) down to −157.64 at n = 201.
- **The softest mode always has wavenumber k = 2** (the ellipse deformation).
- Growth: λ_max(n) ≈ −0.8019n + 0.246 ln n + 2.219 − 2.29/n
  (max residual 0.045 over the sweep); so the poster's constant may be taken
  c_n = |λ_max| ~ 0.80·n (for the log Δ normalization, see below).
- Sharp constant bookkeeping: for feasible arcs from the polygon with
  direction d in the critical cone, log Δ drops as |λ|·dist² where λ is the
  top cone eigenvalue of the Lagrangian Hessian of F — the factor 2 from
  log Δ = 2F cancels against the ½ of the Taylor term. Monte-Carlo check at
  n = 9 along the softest mode with feasibility rescaling: measured
  drop/dist² → 5.476 ≥ predicted sharp minimum 4.751 ✓ (straight-line paths
  drop faster than the optimal arc, as they must).

## Caveats (what this does not settle)
- Floating-point eigenvalue computation, not interval arithmetic — but the
  spectra are bounded away from 0 by ≥ 1.8, far beyond conceivable numerical
  error for 402×402 symmetric eigenproblems.
- Local statement only; says nothing about the global conjecture.
- SOSC uses strict complementarity (μ = (n−1)/16 > 0) + negative definiteness
  on the critical cone; both verified. A referee-grade proof for all odd n
  would need the k-resolved circulant block reduction of H in closed form —
  the observed clean structure (μ exact, k=2 always softest, linear growth)
  suggests this is within reach of a patient hand computation.
