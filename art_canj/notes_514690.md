# MO 514690 — "Do only Mersenne primes have good permutations?"

**Question** (fresh, 0 answers at run time): for odd n > 1, call a permutation
a_1..a_n of {1..n} *good* if every proper consecutive block of length ≥ 2 has
non-integer average. The poster found good permutations precisely for
n = 3, 7, 31 among odd n ≤ 41 and exhibited, for Mersenne primes p,
the zigzag Z_p = (1, p−1, p, p−3, p−2, …, 2, 3). Conjecture: good ⟺ Mersenne
prime.

## Results of this run

### Theorem 1 (zigzag characterization — complete proof)
Write Z_p (odd p ≥ 3) as above; explicitly a_1 = 1, a_i = p+1−i for even i,
a_i = p+3−i for odd i ≥ 3. For a window W = [u, u+L−1] (proper, L ≥ 2) with
sum S:

1. **Interior windows (u ≥ 2) never violate.**
   - L odd: S ≡ +1 (mod L) if u is odd, S ≡ −1 (mod L) if u is even.
     *Proof:* on [u,v] with a_i = p+1−i+2·[i odd], S = L(p+1) − (u+v)L/2 + 2·#odd;
     u+v = 2u+L−1 is even, so the middle term ≡ 0 (mod L), and
     #odd = (L±1)/2 by the parity of u. ∎
   - L even: S ≡ L/2 (mod L). *Proof:* u+v is odd, so (u+v)L/2 ≡ L/2 (mod L),
     and 2·#odd = L. ∎
2. **Odd prefix** (u = 1, L odd): S ≡ −p (mod L). So it violates ⟺ L | p.
   *Proof:* a_1 = 1 replaces the odd-formula value p+2, subtracting p+1 from
   the interior computation: S ≡ 1 − (p+1) ≡ −p. ∎
3. **Even prefix** (u = 1, L even): violates ⟺ p ≡ L/2 − 1 (mod L).
   Moreover such an L ≤ p−1 exists ⟺ p is NOT of the form 2^m − 1:
   if p has t trailing 1-bits and is not all-ones, L = 2^(t+1) ≤ p−1 works
   (p mod 2^(t+1) = 2^t − 1). Conversely for p = 2^m − 1, writing L = 4s
   (parity forces 4 | L), p ≡ 2s−1 (mod 4s) would give 2^m = 2^(a+1)b(2c+1)
   with b odd (s = 2^a b), forcing b = 1, c = 0, hence L = 2p+2 > p−1. ∎

**Corollary.** Z_p is good ⟺ p is a Mersenne prime. More precisely, the
violating windows of Z_p are exactly the prefixes whose lengths are the
nontrivial divisors of p (for p = 2^m − 1): **the zigzag factors its own
length** — e.g. Z_63 is wounded exactly at prefix lengths {3, 7, 9, 21},
Z_2047 at {23, 89}.

Machine certificate: predicted violation set = actual violation set for every
odd p ∈ [3, 401] (774 violations, 0 discrepancies; `good_theorem_check.py`),
plus direct checks of Z_p for p = 2^m−1, m ≤ 13 (`good_constr.py`).

This proves the **"if" direction** of the conjecture for all Mersenne primes
(the poster had it only by example up to 31). It also explains WHY 15 failed
in their search (3·5 | 15) and predicts the failure of 63 before any search.
Note the hypotheses "p is a Mersenne prime" and "p = 2^m−1 with m prime"
first differ at p = 2047 = 23·89, where Theorem 1 says Z_2047 is wounded at
prefix lengths exactly {23, 89} — machine-checked.

### Theorem 2 (dyadic rigidity of any good permutation)
For any good permutation of {1..n}:
- every window of length 2^j ≤ n−1 has sum ≡ 2^(j−1) (mod 2^j)
  (induction: a 2^j-window is two 2^(j−1)-windows each ≡ 2^(j−2), so its sum
  is ≡ 0 (mod 2^(j−1)); non-divisibility forces the odd multiple);
- hence a_{i+2^j} ≡ a_i (mod 2^j) wherever defined (slide the window by 1);
- hence (counting) the position-classes mod 2^j claim distinct residue
  classes mod 2^j; the class i ≡ 0 always claims the residue 0
  (both are the unique classes of size ⌊n/2^j⌋);
- for n = 2^m − 1 with M = (n+1)/2: **a_M = M** and
  **a_{M+t} = a_t ± M** (the "partner map": the upper half is the lower
  half's shadow). This is what makes exhaustive search feasible.

- **n = 63 (composite Mersenne number, beyond the poster's search range) has

- Goodness is preserved by reversal and by complement x ↦ n+1−x (block sums
  map to L(n+1)−S). For n = 7, 31 the four good permutations are exactly the
  orbit {Z_p, rev, comp, rev∘comp}; for n = 3 the orbit degenerates to 2.
  **The zigzag is the unique good permutation up to these symmetries for all
  n ≤ 63.**

### Status of the conjecture
- Mersenne prime ⟹ good exists: **PROVED** (Theorem 1, all p).
- good ⟹ Mersenne prime: verified exhaustively for all odd n ≤ 63.
  The dyadic rigidity (Theorem 2) holds for every odd n without forcing
  n = 2^m − 1 by itself (the counting is consistent for all odd n); the
  necessity must come from the interplay with odd-length windows — e.g. the
  n = 5 hand proof: parity + L=4 force a_3 = 3, then the L=3 windows force
  a_2 + a_4 ≡ 0 (mod 3) (values {2,4}), contradiction. A uniform proof of
  necessity remains open; so does uniqueness at p = 127 (existence is
  Theorem 1; our search engines would need ~10^13 nodes there).

### Ideas that might settle necessity (for a future run)
- mod-3 structure: no 3-window may be all-equal or all-distinct mod 3, so the
  mod-3 trace lives in a 2-letter-window automaton; combine with the dyadic
  skeleton and letter counts via a transfer-matrix count for 3 | n.
- The partner map at level M = largest 2-power: for n ≠ 2^m−1 the singleton
  middle block breaks the mirror; quantify how much freedom it leaves.

exist at EVERY n we tested (exhaustive counts, engine v1 with no dyadic-phase
assumptions):

(counts stabilize into a 2/4 alternation: ≡ 2 mod 4 gives 2, ≡ 0 mod 4 gives

value than even), while even n enjoys a free phase at every dyadic level.
