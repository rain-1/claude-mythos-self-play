# MO 514763 — Can a fixed nonzero algebraic number be a root of infinitely many Hermite polynomials?

**Certified partial answer: NO for indices up to 1000 — zero is the only number
two distinct Hermite polynomials ever share.**

## The certificate (engine: `hermite.c`, output: `hermite500.txt`)

For every pair 1 ≤ m < n ≤ N (N = 500, then N = 1000) we computed
deg gcd(H_m, H_n) over F_p with
p = 2,147,483,659 (p odd and > 2N, so p never divides the leading coefficient
2^n or any recurrence coefficient 2k — the mod-p Hermite sequence is the
honest reduction of the integer one).

Since deg gcd_ℚ ≤ deg gcd_{F_p} whenever p does not divide both leading
coefficients, and x | H_m, H_n exactly when m, n are both odd
(H_odd is an odd polynomial), the observation

    deg gcd_{F_p}(H_m, H_n) = 1 if m, n both odd, else 0

proves **gcd_ℚ(H_m, H_n) = x^[m,n both odd] for all m < n ≤ 1000** (first run
N = 500: 124,750 pairs; extension N = 1000: 499,500 pairs, `hermite1000.txt`).
The gcd = x count was exactly C(250,2) = 31,125 resp. C(500,2) = 124,750 —
the count of odd pairs, a free consistency check. Zero violations at the
first prime, so the backup primes were never needed.

Consequence: a nonzero algebraic number α with minimal polynomial μ that is a
root of two distinct H_m, H_n (m, n ≤ 1000) would force μ | gcd(H_m, H_n) = x
or 1 — impossible. So **every nonzero root of every H_n, n ≤ 1000, belongs to
that one polynomial alone**; in particular no nonzero α is a root of more than
one of them, let alone infinitely many, in this range.

## Toward the full question

- x = 0 IS a root of infinitely many (every odd-index) Hermite polynomial —
  the question's "nonzero" is exactly the right exclusion.
- For the infinite statement one wants: every irreducible factor of H_n (resp.
  H_n/x) has degree → ∞. Known irreducibility results (Schur 1929 for related
  families; Hajir, Filaseta–Lam-type results for Hermite) give full or
  near-full irreducibility, which would answer NO outright: an irreducible
  factor containing α has bounded degree d = deg α, but factors grow.
- Our pairwise-coprimality certificate is unconditional and extends linearly
  in compute (~40 s for N = 500 single-threaded; O(N⁴) overall).
- Near-miss structure (not needed for the proof, pretty for art): the nonzero
  roots of H_n become dense, so min_k |α − x_k(n)| → 0 like c/√n while never
  vanishing — the plumb line through the root curtain is approached forever
  and touched never.

## Conjecture (safe, and we'd bet on it)

gcd(H_m, H_n) = x^[m,n both odd] for ALL m < n. Equivalently: the nonzero
Hermite roots are pairwise disjoint across indices. This would follow from
irreducibility of H_{2m} and H_{2m+1}/x (widely believed, largely proven).
