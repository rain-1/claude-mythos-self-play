# MO 514722 — "Do five lattice points on a circle force 106 inside?"
## Answer-grade notes (exhaustive computation, this run)

**Question** (Aug 2026, score 12): a circle through exactly five points of
ℤ² — what is the minimum number of lattice points in its interior? The
poster's circle 3x²+3y²−x−y=104 (center (1/6,1/6), r²=625/18) has 5 on,
106 in. The top answer (score 22) sketches the finite search (Gauss bound
+ enumerate circumcircles) but reports no execution.

## 1. The answer: yes, 106 is minimal — proved by exhaustive census

**Bound.** Any disk D(c,r) contains ≥ ⌈π(r−1/√2)²⌉ lattice points (the
closed unit squares centered at lattice points cover D(c, r−1/√2)). So a
circle with exactly 5 on-points and interior ≤ 105 has
π(r−1/√2)² ≤ 110 ⇒ **r ≤ 6.63**.

**Search.** Every circle through ≥3 lattice points, anchored by translating
one on-point to the origin, is A(x²+y²)+Gx+Fy=0 with integers A>0,G,F,
gcd=1. Translation classes are keyed by (A, −G mod 2A, −F mod 2A, G²+F²)
(all invariant under re-anchoring; G²+F²=4A²r²). Enumerating all pairs of
lattice points b,c with |b|,|c|,|b−c| ≤ 2r_max and exact integer counting
(`circles.py`, then `circles.c` for the deep census):

- r ≤ 7.3 (covers the bound with margin): 16,718 translation classes.
  Exactly-5 classes: **12**; minimum interior **106** at r = 25/√18 =
  5.8926 — the poster's circle's class. So **106 is minimal**, and the
  witness is unique-up-to-symmetry at minimal radius.
- Deep census r ≤ 32 (`circles.c`): 8,909,743 classes; on-count spectrum
  k ∈ {3,4,5,6,7,8,9,10,12,16,20,24,32} — counts 11,13,14,15,17,… never
  occur below r=32.

## 2. The intuitive explanation of 106

An exactly-odd count forbids the symmetric centers (2c∈ℤ² forces even
count), so the cheapest odd-count centers live at denominator 6 (e.g.
(1/6,1/6)): on-count = #{u²+v²=2N², u≡v≡−1 (mod 6)} for r=N/√18. This
count is **multiplicative**: for N = ∏pᵢ^aᵢ (split primes 5,13,17,…) it
equals ∏(2aᵢ+1). Exactly five points therefore needs N = p², minimal
N = 25, r = 25/√18 ≈ 5.89 — and Gauss then decrees ≈ πr² ≈ 109 interior
points; the champion sheds three below the area (106). **The rim's arithmetic (5 = 2·2+1 needs a square N = p²) sets the radius;
the radius sets the tax.**
