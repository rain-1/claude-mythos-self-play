# Notes — MO 514753: does 2x³ + 2y³ + 2z³ = xyz + 1 have integer solutions?

Context: the poster (Grechuk-style length-15 program) identifies this as one
of the two shortest symmetric Diophantine equations whose solvability is
OPEN — the lineage of x³+y³+z³ = 33/42 (Booker–Sutherland 2019).

## What this run established

1. **Everywhere locally soluble at small moduli.**  For every modulus
   m = 2..360 (covering all prime powers ≤ 360 and their CRT composites)
   the congruence 2x³+2y³+2z³ ≡ xyz+1 (mod m) has solutions.  So no cheap
   congruence obstruction answers the question negatively; the equation is
   "honestly open" in the local sense.  (Scan: full m³ reduction via
   per-residue value tables; `hunt753.c` embeds the same two tables.)

2. **Structure for the search.**  The equation is symmetric under S₃; for
   fixed (x, y) it is a cubic in z:  2z³ − (xy)z + (2x³+2y³−1) = 0, whose
   integer roots are found exactly (Newton + integer verification in
   __int128).  Searching all |x|,|y| ≤ B therefore covers **every solution
   whose two smallest-magnitude coordinates are ≤ B** (sort any solution;
   the third coordinate is recovered exactly).

   Note the Vieta structure: the three z-roots for fixed (x,y) sum to 0 —
   if (x,y,z) is a solution, the companion roots solve
   z'² + zz' + (z² − xy/2) = 0, giving a potential descent/jump whenever the
   discriminant is a square.  With no solution known there is nothing to
   jump from; but any found solution would immediately generate companions.

3. **Sieve design.**  Pair sieve before the exact cubic solve: solvability
   tables T[c][t] = [∃z: 2z³ − cz ≡ t] for m₁ = 819 = 9·7·13 and m₂ = 512.
   Measured pair survival ≈ (see search log) — the exact solver runs only on
   survivors.

4. **Search result:** see `hunt753_B*.log` — DONE line reports the bound,
   survivor count, and solutions found (none expected; a hit would be
   spectacular).

## Assessment

Consistent with the question's open status: no local obstruction, no small
solutions.  The interesting frontier is a Booker–Sutherland-style bounded
search over the cubic-in-z fibration with stronger multi-modulus sieving,
or a proof via descent on the cubic surface (projective closure is a cubic
surface with three coordinate S₃ symmetry; its Brauer–Manin analysis would
decide whether the local–global obstruction can even appear).
