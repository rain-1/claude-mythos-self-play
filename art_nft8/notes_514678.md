# MO 514678 — rational-root permutations of {−N,…,N}: structure, censuses, lemmas

**Question** (Aug 2026, 0 answers at run time): does a permutation
a_0,…,a_{2N} of {−N,…,N} exist for every N such that every quadratic
a_{i−2}x² + a_{i−1}x + a_i has a rational root — equivalently, every
consecutive-triple discriminant a_i² − 4a_{i−1}a_{i+1} is a perfect square?
The posters verified existence for N ≤ 35 via the mirror reduction.

All results below were computed from scratch this run (`perm514678.c`,
independent Python verification of every witness printed).

## 1. The seam lemma (posters' reduction, verified + proved)
If b_1..b_N with |b| a permutation of {1..N} has all internal triples good,
then b + [0] + reversed(−b) is a good permutation of {−N..N}: the three seam
triples have discriminants b_N², 4b_N², b_N² (all squares), and negation +
reversal preserve every discriminant (disc depends on v² and the product of
the outer two).

## 2. Exact reformulation (the "door" identity)
(u,v,w) is good  ⟺  uw = j(v−j) for some j ∈ ℤ.
Proof: v²−4uw = k² ⟺ 4uw = (v−k)(v+k); set j = (v−k)/2 — v,k must share
parity since k² ≡ v² (mod 4) forces (v−k)(v+k) ≡ 0 mod 4 with both factors
even. So the neighbours of v multiply to a product of two integers summing
to v. Special doors:
- j = v/2 (v even): uw = v²/4 — "geometric" triples, disc = 0;
- j = ±1: uw = v−1 or uw = −(v+1) — factor doors: a large value B can sit
  between any factor pair of B−1 (same signs) or of B+1 (opposite signs);
- the LAWFUL family: v = ±(u+w) ⟺ j = u (then uw = u(v−u) needs w = v−u,
  and the sign variant) — disc = (u−w)² resp. (u+w)². These are the only
  j giving w as a *linear* function of (u,v): w = v−u or w = −v−u.

## 3. The lawful walk is an SL₂(ℤ) walk, and its meter
The two lawful moves act on end-pairs as M1 = [[0,1],[−1,1]] (order 6) and
M2 = [[0,1],[−1,−1]] (order 3), both in SL₂(ℤ); M1·M2⁻¹ = [[1,0],[2,1]] is
a transvection, so the lawful "rhyme group" is infinite.
Mod 2 both moves read w ≡ u+v: parities follow the Fibonacci meter, whose
orbits are the 3-cycle O,O,E (odd fraction exactly 2/3) and the fixed point
E,E (all even). But {1..N} has ⌈N/2⌉ odd values.

**Proposition (death of the pure-lawful poem).** A b-solution using only
lawful triples exists iff N ≤ 5. For N=6 the meter alone kills it (a
6-window of the OOE meter carries 4 odds; {1..6} has 3); for N ≥ 7 the
census below is empirical (0 pure-lawful among all solutions ≤ 10), with
the meter argument killing every N with ⌈N/2⌉ ∉ {⌊2N/3⌋..⌈2N/3⌉+1}, i.e.
all N ≥ 9 as well.
Exhaustive: pure-lawful / all b-solutions = 2/2, 8/8, 24/24, 16/16, 16/16
for N=1..5, then 0/16, 0/24, 0/64, 0/24, 0/192 for N=6..10.
**Every solution beyond N=5 must break meter with "lucky" squares.** In
found witnesses the lawful fraction stays ≈ 0.35–0.55 through N=40.

## 4. No three consecutive odds (mod-8 wall)
If u,v,w are all odd, disc = v²−4uw ≡ 1−4 ≡ 5 (mod 8), never a square.
So odd values appear in runs of ≤ 2 throughout any solution.

## 5. Neighbours of 0
If 0 is interior with neighbours u,w: disc = −4uw must be a square, so
u,w have opposite signs and |u|·|w| is a perfect square. (The mirror
construction's u = b_N, w = −b_N is the simplest case.)

## 7. Existence
Randomized DFS (Warnsdorff + a bias toward consuming large values early,
plus randomized restarts) found solutions for **every N ≤ 49**. N ≤ 44
fall in seconds; **N = 49 is the first genuinely hard instance**: several
independent seeds × 400 restarts and one direct (non-mirror) search all
failed before one seed found a witness after 118 restarts (≈ 187 s CPU —
vs < 2 s typical for N ≤ 44). Beyond it the wall is broad, not a blip: with the same
budgets N=50 resisted its first 15 minutes, and longer runs (≈15 min and
≈33 min with deeper backtracking) failed at N=60 and N=100. So for THIS
search family the practical frontier is N ≈ 50; either solutions thin
out dramatically there (the b-count dip at N=17 shows density is not
monotone) or — more likely, given the door-density heuristic below —
the pair-state DFS simply needs better global guidance (e.g. matching
big values to their factor-door pairs *before* sequencing). We lean
strongly toward existence for all N, but a fundamentally better search
or an explicit construction is the open engineering problem. The N = 49

## 8. Heuristic and conjecture
The door identity gives each value v ≈ Σ_j d(|j(v−j)|) unordered neighbour
pairs — on average ~c·N·log N doors per value, so the triple-compatibility
"graph" gets denser as N grows, and the usual Hamiltonicity heuristics
predict solutions for all N with the count growing super-exponentially.
**Conjecture: good permutations exist for every N; the b-count sequence
grows faster than any polynomial.**
The genuine risk is small-N accidents (cf. N=6 collapse, N=49 hardness),
not large N.

## 9. Answer-grade advice to the posters
- search the *signed* mirror sequence with the pair-state DFS + Warnsdorff
  (code here); the state (u,v) plus the used-set is all that matters;
- use the door identity uw = j(v−j) to enumerate candidate neighbours of
  big values instead of testing all w;
- expect non-monotone difficulty; a failed budget at one N says little.
