# MO 514559 — "Closed form for the nimbers of this mesh game?" — ANSWERED (finite case, with proof)

**Game.** Piles (x, y, z); a move removes ≥1 stones from *exactly two* piles
(any amounts, independently). t(x,y,z) = Grundy value.

## Theorem

For all finite x, y, z:

    t(x, y, z)  =  min( x+y,  y+z,  z+x,  ⌊(x+y+z)/2⌋ ).

Equivalently t = min(s − M, ⌊s/2⌋) with s = x+y+z, M = max(x,y,z): the
"addition table" t = s − M where one pile dominates (M > ⌈s/2⌉), truncated
at 45° by the balanced ceiling ⌊s/2⌋ — exactly the corner-truncated contours
the poster observed.

Special cases: t(x,y,0) = min(x,y); t(m,m,m) = ⌊3m/2⌋; t = 0 iff at least
two piles are empty (the P-positions are just the three axes).

## Proof

Write f(x,y,z) for the right-hand side. WLOG x ≤ y ≤ z (the game is
symmetric), so f = min(x+y, ⌊s/2⌋).

**Lemma 1 (every move strictly decreases f).**
A move lowers s by at least 2, so ⌊s'/2⌋ ≤ ⌊s/2⌋ − 1.
- If f = ⌊s/2⌋: f' ≤ ⌊s'/2⌋ < f.
- If f = x+y < ⌊s/2⌋ (so z is the strict maximum): for any successor, f' is
  at most the sum of its two smallest piles, hence at most any pairwise sum.
  Cutting (x,y): f' ≤ x'+y' ≤ x+y−2. Cutting (x,z): f' ≤ x'+y < x+y.
  Cutting (y,z): f' ≤ x+y' < x+y. In all cases f' < f. ∎

**Lemma 2 (all lower values are reached).** Let v < f. We exhibit a move to
a position with f-value exactly v.

*Case A: v ≤ x.* Cut y,z down to y' = ⌊v/2⌋, z' = ⌈v/2⌉ (so y'+z' = v).
Strictness: if y ≤ ⌊v/2⌋ then x+y ≤ 2y ≤ v < f ≤ x+y, contradiction — so
y' < y; similarly z' < z except in the corner x=y=z=(v+1)/2 with v odd,
which forces 2m−1 = v < f = ⌊3m/2⌋ ⟹ m ≤ 1, i.e. position (1,1,1), where
only v = 0 is required and (0,0,1) supplies it. In the successor (x,y',z'),
max = x (as y',z' ≤ ⌈v/2⌉ ≤ x), the smallest pairwise sum is y'+z' = v
(since x ≥ ⌈v/2⌉ gives x+y' ≥ v), and ⌊(x+v)/2⌋ ≥ v since x ≥ v. Hence
f' = v.

*Case B: x < v < f.* Cut y,z to y', z' with y'+z' = 2v − x, choosing
y' in the interval I = [max(v−x, 2v−x−z+1), min(y−1, v)] and z' = 2v−x−y'.
I is nonempty: v ≤ x+y−1 gives v−x ≤ y−1; 2v ≤ s−2 (from v ≤ ⌊s/2⌋−1)
gives 2v−x−z+1 ≤ y−1; v ≤ x+z−1 gives 2v−x−z+1 ≤ v; and v−x ≥ 1 ≥ 0.
The successor has s' = 2v, and all pairwise sums ≥ v (y' ≤ v ⟺ x+z' ≥ v,
y' ≥ v−x ⟺ x+y' ≥ v, y'+z' = 2v−x > v), so f' = min(pairwise, ⌊2v/2⌋) = v.
Both cuts are strict by the interval bounds. ∎

By induction on s, Lemmas 1–2 give t = f: the successors' f-values include
every value 0..f−1 and never f, so mex = f. ∎

## Machine verification

- Formula ≡ full Grundy DP on the cube 200³ = 8,000,000 states (prefix-OR
  bitset DP, `mesh_small.py` / `mesh_verify.py`): **equal everywhere**.
- Lemma 2 checked exhaustively for all positions with piles ≤ 30 and all
  v < f: no missing value, ever.
- t(x,y,0) = min(x,y) and full symmetry verified.

## Remarks

- The two-pile trace t(x,y,0) = min(x,y) is the quadrant-mex game.
- For ordinal piles the natural guess replaces + by the natural (Hessenberg)
  sum and ⌊s/2⌋ by its natural half; we have not pursued the transfinite
  induction, but the finite proof's two lemmas only use order arithmetic
  that survives naturally. Left open here.
