# MO 516094: rational curves on S : F(a,b) = F(c,d),  F = ab(a+b)(a²+ab+b²)

Note a⁵+b⁵+(−a−b)⁵ = −5F(a,b). S ⊂ P³ is the quintic F(a,b) − F(c,d) = 0.
Scripts are in this directory (verify.py, lines_planes.py, residual.py, cubic.py, extra_curves.py,
enum.c, post.py, cwlib.py, cwbase.py, gn.py, gnreal.py).

## 1. CW parametrization, symmetries, geometry of S  (verify.py, sympy, exact)

* The Choudhry–Wroblewski formulas satisfy F(a,b)=F(c,d) identically. In homogeneous form the curve has degree 16:
  a = u(u+v)(u¹⁰−4u⁵v⁵−v¹⁰)Φ₁₀(u,v), b = 2uv⁵(3u¹⁰+v¹⁰), c = v(u+v)(u¹⁰+4u⁵v⁵−v¹⁰)Φ₁₀(u,v),
  d = v(u−v)(u¹⁰−4u⁵v⁵−v¹⁰)Φ₅(u,v), where Φ₁₀ = u⁴−u³v+u²v²−uv³+v⁴ and Φ₅ = u⁴+u³v+…+v⁴. The gcd is 1.
* **How CW works.** Put t = u⁵/v⁵. Then [a:b] = [(t+1)(t²−4t−1) : 2(3t²+1)] and
  [c:d] = [(t+1)(t²+4t−1) : (t−1)(t²−4t−1)] together define a rational curve B of bidegree (3,3) in P¹×P¹, and
  **F(c,d) = t·F(a,b) exactly** (sympy: the ratio is exactly t).
  The map S ⇢ P¹×P¹, [a:b:c:d] ↦ ([a:b],[c:d]), is a μ₅-cyclic cover branched over the 10 lines {x = root of F} and {y = root of F}.
  A curve C ⊂ P¹×P¹ lifts to a rational curve on S iff the cover z⁵ = F(ψ)/F(φ) on its normalisation is branched at exactly 0 or 2 points.
  For CW the branch points are t = 0 and t = ∞. The other 14 intersections of B with the branch lines occur in matched pairs at the 25 "grid points" (rᵢ,rⱼ).
  B passes through 10 distinct grid points and has nodes at 4 of them (its arithmetic genus is 4).
  Its stabiliser in Aut_Q(S) has order 4 (computed numerically). It contains the symmetries behind u/v ↦ v/u and u/v ↦ −u/v, which give the same orbit. So **the CW construction gives 18 distinct Q-curves**.
  The μ₅ part of Aut(S) fixes the CW curve, since u ↦ ζu leaves it invariant.
* **Symmetries of F.** Over C, exactly 30 matrices M ∈ GL₂(C) satisfy F∘M = F (sympy solve): S₃ × μ₅.
  Over Q there are exactly 6: the S₃ that permutes (a, b, −a−b). It is generated by (a,b)↦(b,a) and (a,b)↦(b,−a−b). The map −I sends F to −F.
* **Root configuration.** The roots of F on P¹ (t = a/b) are {0, ∞, −1, ω, ω²}. The projective stabiliser of this 5-point set is S₃ (order 6), with orbits {0,∞,−1} and {ω,ω²}.
  Here {ω,ω²} is the pair of fixed points of the order-3 map t ↦ −1/(t+1), and {0,∞,−1} is a regular 3-orbit.
  So F ≅ xy(x³ − y³) projectively: two "poles" plus one equatorial triangle. The finite subgroups of PGL₂(C) that contain S₃ are D₃ₘ, S₄ and A₅. Their orbit sizes are {2, 3m, 3m, 6m}, {6, 8, 12, 24} and {12, 20, 30, 60}. None of these lets a 5-point set be invariant for m ≥ 2, so S₃ is the full stabiliser.
* **Aut(S)** ⊇ {(M,N): F∘M = F∘N = λF}/scalars ⋊ (swap (a,b)↔(c,d)). This group has order 2·30·30/5 = 360. Over Q the group Aut_Q has order 2·36 = 72: S₃×S₃ ⋊ swap.
* **S is smooth**: the gradient vanishes only if a=b=0 and c=d=0. So S is a smooth quintic surface: general type, K = O(1), p_g = 4, q = 0, K² = 5, c₂ = 55.
* **Lines: exactly 55** (proof plus numerical check in lines_planes.py).
  - 25 "grid" lines {ℓᵢ(a,b) = 0 = ℓⱼ(c,d)}, one for each pair of roots.
  - 30 "graph" lines {(c,d) = M(a,b)}, M ∈ S₃×μ₅. Only the 6 with M ∈ S₃ are defined over Q; these are the trivial solutions.
  - Proof that there are no others: if [a:b] is constant on a line L, then L lies in the plane b = pa. That plane meets S in a⁵F(1,p) = F(c,d). This is a smooth plane quintic when F(1,p) ≠ 0, and 5 grid lines when F(1,p) = 0. Otherwise both projections are isomorphisms, so L is the graph of a linear M with F∘M = F.

## 2. Integer search (enum.c, post.py)

The search hashes F(a,b) over all −N ≤ a ≤ b ≤ N with F > 0, using 128-bit arithmetic and multi-pass hash partitioning. It keeps the groups that contain two different S₃-orbits, then keeps the pairs with gcd(a,b,c,d) = 1.
Counting is as follows. A "solution" is an unordered pair {(a,b),(c,d)} with a ≤ b, c ≤ d, F > 0, primitive, and (c,d) ∉ S₃·(a,b). A "class" is an orbit under Aut_Q (S₃ × S₃ × swap × sign).

| N (box max(|a|,|b|,|c|,|d|) ≤ N) | solutions | classes |
|---|---|---|
| 2 000 | 9 | 1 |
| 10 000 | 9 | 1 |
| 30 000 / 50 000 / 60 000 — **incomplete**: only 10/32, 22/128 and 33/128 hash passes finished before the time budget ran out | – | the N=60000 partial run found 1 more class |

* The **smallest nontrivial primitive solution** is
  **1258⁵ − 1153⁵ − 105⁵ = 1037⁵ − 582⁵ − 455⁵**, i.e. F(−1258,105) = F(−1037,455) = 222585961555230, with height 1153 in the form (−1037, 582, 105, 1153).
  It is the only class up to height 10⁴ (complete search).
* The partial N = 60 000 run found a second class: (−44667, 25403, 3914, 51858), F = 32913878755098321868608.
* **Neither class lies on any of the 18 CW curves.** The test checks all 72 Aut_Q images by solving for a rational t on the base curve B and checking τ⁵ = t.
* The smallest-height point of the CW family is (59070, 12292, 37983, 27745), from u/v = 2. It has height 59070, so the CW family has no points in the completely searched box (N = 10⁴).
* solutions.tsv lists every solution for N = 10⁴: the 9 representatives of the one class. solutions_60000_partial.tsv holds the second class.
  small_pairs.json holds all 19 known points of height ≤ 60 000, in canonical form, sorted by height: 9 + 9 representatives of the two classes, plus the CW point (12292, 59070, 27745, 37983).
  Only 19 exist, not 40. The list is complete only up to height 10⁴.

## 3. Other curves on S

**(a) Planes through two intersecting lines** (lines_planes.py, residual.py, cubic.py). There are 115 such planes.
* 10 planes {ℓᵢ(a,b)=0} or {ℓⱼ(c,d)=0}: each meets S in 5 lines.
* 45 planes containing 3 lines, where the residual is an **irreducible conic**. Nine of them are defined over Q; they form the Aut_Q-orbit of the plane c = a. There
  F(a,b) − F(a,d) = a(b−d)(a+b+d)(a²+ab+b²+ad+d²).
  The conic a²+ab+b²+ad+d² = 0 (with c = a) is a positive-definite form, so it has no real points. It is a Q-curve of genus 0 but **not Q-parametrisable**. Over Q(ω) it is parametrised (verified exactly) by
  (a,b,c,d) = (ω²s² + ω, s²+s+1, ω²s² + ω, (2ω²+1)s − ω).
  The other 36 conics are its μ₅-twists.
* **60 planes containing exactly 2 lines.** These are graph lines L_M paired with L(ω,ω), L(ω,ω²), …, e.g. the plane a − c = ω(b − d). The residual is a **smooth plane cubic**: F(a,b) − F(c,d) restricted to the plane factors over Q(√−3) as (b−d)(a−ωb)·cubic, and a Gröbner basis shows the cubic has no singular point.
  **So S contains 60 elliptic curves (plane cubics). None is defined over Q:** their planes all involve ω, and the rational planes are the 9 conic planes above.

**(b) New rational sextics, over Q(ω, 3^{1/5}).** A Möbius map g with g(R∖{p}) = R∖{q} but g(p) ≠ q gives a bidegree-(1,1) base curve with exactly 2 branch points, hence a rational curve of degree 6 on S. There are **54** such (g, 4-set) incidences (mob4.py). None is real.
Example: g = [[ω², −1],[1, −ω²]] sends 0→ω, ∞→ω², ω→0, ω²→∞, −1→1, and F(g(a,b)) = 3ω²·(a−b)/(a+b)·F(a,b). This gives the rational sextic
  (a,b,c,d) = (σ(ρ⁵+σ⁵)/2, σ(ρ⁵−σ⁵)/2, ρ/θ · g((ρ⁵+σ⁵)/2, (ρ⁵−σ⁵)/2)), with θ⁵ = 3ω².
F(a,b) − F(c,d) ≡ 0 was verified exactly with sympy (extra_curves.py).
This is the bidegree-(1,1) analogue of CW. CW is a bidegree-(3,3) version of the same mechanism: matched grid points everywhere except 2 branch points.

**(c) Why Q-curves must look like CW.** Take a Q-rational curve on S that is not a line and does not split.
* Its two branch points on P¹ must be rational. If they were conjugate, the exponents j and 5−j at them would have to agree mod 5, which is impossible.
* So after a change of coordinates over Q it has the form τ ↦ (τʲA(τ⁵), τʲB(τ⁵), C(τ⁵), D(τ⁵)), where A, B, C, D ∈ Q[t] satisfy **F(C,D) = tʲ·F(A,B)**, 1 ≤ j ≤ 4. The constant can be absorbed, since gcd(j,5) = 1.
* In the split case (j = 0) the condition is F(C,D) = F(A,B), the case of the lines and the conics.

Parameter count for kx = ky = k: there are 4k+2 unknowns after gauge fixing and 5k+j+1 equations. The system is overdetermined by k+j−1, which is 3 for CW. So such curves are "unexpected", and CW is special.

**Numerical search for further solutions** (gn.py, gnreal.py, Gauss–Newton from random starts on F(C,D) = tʲF(A,B)):
* Without filtering, many near-degenerate pseudo-solutions converged. These approach the line families, with condition numbers around 10⁴. After filtering them out (normalised F(A,B) and an isolated-root test), runs of about 130 starts per configuration over (k,k,j) with k ≤ 4 found nothing. They did not recover CW either.
* **This search is inconclusive, not negative evidence.** Random-start Newton is too weak for these overdetermined systems; a proper homotopy or Gröbner method on structured ansätze (prescribed grid incidences) would be needed.

## 4. Conjecture

**Conjecture.** Every rational curve on S defined over Q (equivalently, every non-trivial polynomial/rational parametric solution of (1) over Q) is one of the 18 Aut_Q-images of the Choudhry–Wroblewski curve.
Geometrically there are more rational curves: the 45 conics, the degree-6 curves of §3(b), and the CW family. There are also 60 elliptic curves. None of these extra curves is Q-parametrisable.

Evidence:
* (i) S is a smooth quintic of general type, so rational curves are rigid and sparse.
* (ii) Every extra geometric rational or elliptic curve found is non-real, or has no real points.
* (iii) Every Q-curve must satisfy the overdetermined CW-type identity of §3(c).
* (iv) In the box up to 10⁴ the integer points are extremely sparse (one class). None lies on a known curve, consistent with "sporadic points plus finitely many curves" (Bombieri–Lang).

Weak point: the search for further CW-type identities (§3c) was inconclusive. It is the natural next step: impose prescribed grid incidences on a (k,k) curve and solve exactly.
